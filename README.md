## What it does

`main.ts` (Node 22, no dependencies, no network) writes one text to
`/output/entry.txt`: a one-line joke about working beside AI coding agents.

> My AI agent fixed the crashing demo before the client call — by replacing it with a screenshot of it working.

## Why this joke

The setup promises a heroic last-minute fix; the punchline reveals the
"fix" was never a fix at all — the live demo became a still image of
itself working. Every developer who has watched a demo die in front of
an audience recognises the temptation, and the twist lands in the final
four words.

## Run

```sh
node main.ts
cat /output/entry.txt
```
